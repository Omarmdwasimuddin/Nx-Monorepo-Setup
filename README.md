## Nx Monorepo Setup

#### Nx Install
```bash
npm i -g nx
```
> version check
```bash
nx --version
```
> or,
```bash
npx nx --version
```
---

#### Notun Nx Workspace toiry koro
```bash
npx create-nx-workspace@latest my-workspace
```
